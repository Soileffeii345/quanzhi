# 泉知 Quanzhi

泉知是一款面向评级币收藏者的多来源成交查询产品。用户可以输入钱币名称或 NGC / PCGS 评级盒号，也可以上传评级盒标签照片，查看当前已收录并经过核验的历史成交、价格趋势、评级差异和原始交易证据。不同平台覆盖程度会在详情页明确展示。

线上体验：本次验收部署后更新

## 产品能力

- 评级盒号精确查询与官方证书入口
- 币名关键词、模糊匹配和搜索建议
- 图片 OCR 识别盒号，并要求用户逐位确认
- 历史成交、价格趋势、评级和平台对比
- 日期、价格及交易状态筛选
- CSV 导出、搜索历史和本地收藏
- 首页、币种详情、收藏和数据库浏览页面
- 静态数据优先加载，API 后台补充

## 数据口径

公开成交必须通过发布规则，并包含完整盒号、成交时间和可回溯证据链接。首页统计由生成后的数据清单读取，不在页面中写死。

截至 2026-08-10 的本地审计结果：

- 8,494 条经原交易页复核的成交
- 8,182 个唯一评级盒号
- 2,211 个归一化币种
- 523 条在售记录（赵涌 520 条、易金首批接入 3 条；不计入成交样本）

数据来自平台公开页面，仅用于信息检索和历史比较，不构成投资建议。

### 当前覆盖说明

- 赵涌在线为当前主要数据来源，并每日复核在售状态。
- 易金在线在售处于 Beta 接入，优先覆盖金币、银币、熊猫币；当前数量不代表平台全部库存。
- 网站采用定期批量更新，不是分钟级实时数据库，也不宣称全平台全量覆盖。
- 只有通过盒号、价格、时间、证据图和原链接检查的数据才进入公开页面。

## 本地运行

```bash
npm install
npm run dev
```

## 质量检查

```bash
npm run data:audit
npm run lint
npm test
```

`npm test` 会先执行生产构建，再验证首页服务端渲染和发布数据清单的一致性。

## 数据更新

```bash
npm run data:update
```

生产环境采用 GitHub 静态 JSON + Vercel：每日任务分批采集和核验，通过审计后重新生成公开文件；失败时保留上一版。完整 SQLite 是工作数据库，应单独保留备份，不直接暴露给网站用户。

完整静态导出可运行：

```bash
npm run data:export
```

该命令先审计 SQLite 数据，再重新生成盒号索引、币种索引和数据库浏览页。

## 技术结构

- Next.js 16、React 19
- SQLite 数据处理与静态 JSON 发布层
- Tesseract.js 浏览器端 OCR
- GitHub Actions 自动化
- Vercel Hobby 生产部署（个人作品集免费方案）

## 项目原则

1. 证据优先：没有可回溯证据的记录不进入可信成交统计。
2. 口径一致：首页、详情、导出与数据库页使用同一发布规则。
3. 不制造估值：展示历史样本、时间和样本量，不用单一价格替代用户判断。
4. 失败可恢复：数据更新失败时保留上一版可用数据和运行记录。
