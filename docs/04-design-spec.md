# 设计规范

## 1. 设计目标

简洁、可信、易搜索。首屏让用户立即知道“输入关键词或评级盒编号，查询跨平台行情”。

## 2. 信息层级

1. 搜索输入与搜索按钮。
2. 匹配到的钱币品种或具体盒币。
3. 行情概览。
4. 历史成交与当前市场。
5. 数据来源、更新时间和口径说明。

## 3. 核心页面

- 首页：品牌、主搜索、搜索示例、热门品种和数据声明。
- 搜索结果：候选币种、筛选、空状态与纠错提示。
- 钱币详情：资料、行情、成交、在售/拍卖和收藏。
- 编号结果：具体盒币信息及可确认的成交轨迹。
- 个人区域：收藏与搜索历史的样品体验。

## 4. 交互标准

- 搜索框支持回车提交，按钮有明确文字。
- 输入示例同时覆盖关键词、组合关键词和盒编号。
- 宽泛搜索不得直接给出混合价格。
- 切换筛选后展示当前结果数量。
- 外部链接明确标注将前往原平台。
- 无结果时提供修改关键词和查看相似币种的建议。

## 5. 视觉标准

- 使用克制的中性色作为背景，金色只用于重点和品牌识别。
- 不使用大面积高饱和金色，避免廉价感。
- 金额与关键数字使用更醒目的字号和字重。
- 平台、数据状态、评级信息使用统一标签样式。
- 桌面端保持舒适留白；移动端保证按钮和筛选可触摸。

## 6. 内容标准

- 使用普通收藏者能理解的语言。
- 不使用“绝对真实”“全网最低”等无法证明的表述。
- 演示记录统一显示“演示数据”。
- “最新成交价”必须同时展示更新时间和计算范围。
- “未找到”不等于“从未成交”，文案需避免误导。
