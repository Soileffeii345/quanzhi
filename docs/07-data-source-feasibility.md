# 数据来源可行性初查

更新日期：2026-08-02

本结论用于决定“泉知”样品的真实数据验证顺序，不等于平台已经授权数据转载。正式采集前仍需检查服务条款、robots 规则、访问频率和字段版权。

## 分级说明

- A：存在公开网页和可检索字段，适合优先做小规模只读验证。
- B：部分公开，但历史、价格或详情存在账号/规则限制，需要进一步验证。
- C：主要依赖 APP、小程序或登录态，不适合首批网页采集。
- D：公开协议对第三方展示存在明显限制，未经许可只提供平台入口。

## 新发现的候选来源

- 银元查价宝：公开官网描述支持按 PCGS 评级 ID 查询历史成交链，但数据使用授权和接口尚未确认。
- 钱币价格查：公开网页提供历史成交与今日截标入口，但需确认其数据来源和转载许可。

这两个候选来源与用户提到的“币查查、币盘盘”名称相近但不能直接认定为同一产品。

## 推荐的真实数据验证顺序

1. 邮宝：验证公开买卖盘的关键词、价格、时间和链接字段。
2. 赵涌在线：验证公开在拍和近期成交字段，严格限制在非会员页面。
3. 易金在线：验证页面稳定性及是否允许低频采集。
4. 金币云集：检查独立网页端是否提供无需登录的公开列表。

## 首次技术验证的停止条件

- 页面要求登录、验证码或实名认证。
- robots 或服务条款明确禁止自动访问。
- 需要调用未公开的 APP/小程序接口。
- 访问触发风控、封禁或显著影响平台服务。
- 商品图片、详情或历史价格只能通过付费会员获得。
