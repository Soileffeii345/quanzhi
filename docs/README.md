# 钱币行情聚合网站：项目文档中心

本目录保存项目从需求确认、方案设计、开发、验收到复盘的完整材料，既服务于项目交付，也用于产品经理求职作品集。

1. [产品需求文档](./01-product-requirements.md)：用户、场景、范围、功能和验收标准。
2. [版本路线图](./02-roadmap.md)：按小步稳定推进的阶段计划。
3. [技术与数据方案](./03-technical-and-data-plan.md)：系统结构、数据边界和风险。
4. [设计规范](./04-design-spec.md)：页面结构、交互及视觉原则。
5. [验收与测试标准](./05-acceptance-and-test-plan.md)：每个版本完成的判断标准。
6. [产品经理作品集记录](./06-portfolio-case-study.md)：简历和面试可使用的项目证据。
7. [数据来源可行性初查](./07-data-source-feasibility.md)：候选平台分级、风险与验证顺序。

## 维护规则

- 需求发生变化时，先更新产品需求文档，再进入开发。
- 每个阶段开始前明确目标、范围和验收标准。
- 每个工作日或关键变更后更新 `development-logs/`。
- 演示数据必须明确标注，不能被表述为真实成交数据。
- 每次只推进一个小版本；通过验收后再进入下一阶段。
